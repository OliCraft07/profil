# Oliver – Profesijný profil

Študent 4. ročníka odboru Informačné a sieťové technológie na SPŠE Hálova 16 v Bratislave. Hrávam hádzanú, pôsobím ako rozhodca v Slovenskom handballovom zväze a záujem mám o siete, programovanie a tvorbu digitálneho obsahu.

## Kľúčové zručnosti

PHP, C#, objektovo orientované programovanie, HTML, JavaScript, Cisco Packet Tracer, konfigurácia sietí (VLAN, DHCP, EtherChannel, HSRP), návrh databázových schém (DBML), Canva, tvorba obsahu pre Instagram, práca s AI nástrojmi, Lovable, tímová spolupráca, prezentovanie

## Projekty

### Aplikácia na hodnotenie filmov
Osobná webová aplikácia, v ktorej môžem hodnotiť filmy a viesť si prehľad o pozeraných titulach.
**Technológie:** Lovable, AI asistent v programovacom prostredí

### WLAN projekt v Cisco Packet Tracer
Návrh siete s topológiou, IP adresovaním, DHCP a zabezpečením WiFi cez WPA2 vrátane presmerovania portov.
**Technológie:** Cisco Packet Tracer

### Webová aplikácia v PHP
Školský projekt so správou používateľov, prihlasovaním, CRUD operáciami, administračným rozhraním a nahrávaním súborov.
**Technológie:** PHP, HTML, CSS

- Hráč hádzanej približne 8 rokov, v tíme často preberám vedenie skupiny.
